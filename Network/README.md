# Network 공부 노트

네트워크 기초부터 개인 실습과 장애 진단 흐름까지 순서대로 학습하는 자료입니다. 개인 학습용이며 특정 회사나 업무 환경을 다루지 않습니다.

## 공부 순서

| 순서 | 주제 | 학습 결과 |
|---|---|---|
| 1 | 네트워크·인터넷 기본 구조 | 클라이언트, 스위치, 라우터, 서버의 역할을 설명합니다. |
| 2 | IPv4·서브넷·게이트웨이 | 주소와 CIDR 표기를 읽고 같은 네트워크인지 판단합니다. |
| 3 | DHCP·DNS | IP 설정과 이름 조회 과정을 구분합니다. |
| 4 | 이더넷·스위치·VLAN | MAC 주소, 스위칭, 브로드캐스트 영역, access/trunk 개념을 익힙니다. |
| 5 | 라우팅·NAT | 다른 네트워크로 패킷이 이동하는 경로를 추적합니다. |
| 6 | TCP·UDP·주요 포트 | 연결, 포트, 서비스가 통신에 어떻게 쓰이는지 익힙니다. |
| 7 | 무선 네트워크·방화벽 기초 | 무선 연결과 기본 접근 제어를 설명합니다. |
| 8 | 진단 명령과 장애 분석 | 증상에 맞는 확인 순서와 근거를 기록합니다. |

각 주제는 `개념 → 예시 → 직접 확인 → 내 말로 설명 → 모르는 점 기록` 순으로 진행합니다. 앞 주제에서 막힌 내용은 질문 기록에 남기고, 이해한 뒤 다음 단계로 넘어갑니다.

## 개인 실습 원칙

- 집에서 소유하거나 사용 권한이 있는 장비와 가상 환경에서만 실습합니다.
- 실제 네트워크 설정을 변경하기 전에 현재 설정과 복구 방법을 기록합니다.
- 실습하지 않은 내용은 완료했다고 표시하지 않습니다.
- 질문은 표현을 다듬지 않아도 됩니다. 모르는 문장을 그대로 질문 기록에 남기고 답변과 예시를 보충합니다.

## 학습 환경 메모

아직 확정하지 않은 항목입니다. 현재 장비와 학습 시간에 맞춰 실습 계획을 조정합니다.

- 사용 가능한 컴퓨터와 운영체제: 미정
- 가상머신 실행 가능 여부: 미정
- 주당 학습 가능 시간: 미정
- 네트워크 경험 또는 특히 어려운 주제: 미정
